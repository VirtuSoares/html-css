# 📌 Entregável de Desenvolvimento Web – Estilização do Formulário (Semana 02)

Este repositório contém a estilização do **Formulário de Inscrição do Blog**, desenvolvida com **HTML5** e **CSS3**, focando na criação de um layout responsivo, organizado e com boa usabilidade através de **Flexbox**.

---

## 🎯 Objetivo da Atividade
* Estruturar e alinhar elementos de formulário utilizando **CSS Flexbox** (`display: flex`, `gap`, `flex-direction`).
* Aplicar estilizações modernas em elementos de entrada (`<label>`, `<input>`, `<select>` e `<button>`).
* Garantir hierarquia visual com containers organizados, espaçamentos adequados (`padding`, `margin`) e bordas arredondadas (`border-radius`).
* Implementar estados interativos no botão de envio (`:hover` e `cursor: pointer`).
* **Bônus:** Alinhamento dos campos de Nome e E-mail lado a lado em telas maiores utilizando `justify-content: space-between`.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do formulário.
* **CSS3:** Estilização visual, variáveis de cor e layout flexível (Flexbox).
